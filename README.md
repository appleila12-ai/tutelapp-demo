# TutelApp — frontend

App Expo (expo-router). Vedi il README principale e `MULTI-COMUNE.md` nella cartella superiore.

```bash
yarn install
yarn start     # sviluppo
yarn build     # versione web in dist/ + anteprime dei link per Comune
```

Variabili d'ambiente utili:

- `EXPO_PUBLIC_BACKEND_URL`: indirizzo del backend
- `EXPO_PUBLIC_COMUNE`: Comune predefinito (se il link non ne indica uno; di base `sarzana`)
- `SITE_URL`: indirizzo pubblico del sito, per le immagini di anteprima dei link
